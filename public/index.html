Energy Consumption Pattern Analysis (PCA + K-Means)

This Vercel site is a static landing page. The interactive dashboard is a Streamlit app. Vercel Python functions cannot run Streamlit (they expect a Flask/FastAPI app or handler).

Source: GitHub repository

Run the dashboard locally

py -m pip install -r requirements.txt
py -m streamlit run streamlit_app.py

Host the dashboard

  • Streamlit Community Cloud: deploy streamlit_app.py from this repo.
  • Render / Docker: see render.yaml and Dockerfile in the repo.

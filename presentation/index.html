Problem Statement

Shape-first segmentation for demand response

🎯 Core Challenge

Group households by daily load curve shape, not total consumption. Similar rhythms deserve similar advice.

📐 Scale Invariance

Two consumers with identical 24-hour profiles but different magnitudes should cluster together.

⏰ Timing Critical

Same daily total but opposite peak hours means different behavioral patterns — must separate.

✅ Goals

Reproducible pipeline, seasonal stability, real-world validation pathway, explainable clusters with SHAP.

Limitations

Known constraints and planned improvements

⚠️ Synthetic Data

Ground-truth archetypes enable ARI validation but lack real-world noise complexity. External adapter tested on 1 meter dataset.

🔧 Fixed K

K=4 validated for this dataset. Real deployments need adaptive K selection or hierarchical clustering for variable populations.

📅 Annual Scope

365-day analysis captures seasonality but assumes stationarity. Multi-year data would reveal long-term behavioral drift.

🎯 Feature Engineering

51 features manually curated. Automated feature discovery (deep learning embeddings) could uncover hidden patterns.

RESEARCH PROBLEM

GROUP BY SHAPE, NOT SCALE

TRADITIONAL APPROACH

Segment households by total consumption (kWh/day)

❌ Miss behavioral patterns
❌ Ignore timing
❌ Scale-dependent
→

SHAPE-FIRST SEGMENTATION

Group by 24-hour load curve shape, independent of magnitude

✓ Timing matters
✓ Scale-invariant
✓ Behavioral archetypes

PRIMARY OBJECTIVE

Two households with identical 24-hour profiles but different magnitudes should cluster together. Two with same daily total but opposite peak hours should separate.

LIMITATIONS & FUTURE WORK

⚠️ SYNTHETIC DATA

Ground-truth archetypes enable ARI validation but lack real-world noise complexity. External adapter tested on 1 meter dataset.

🔧 FIXED K

K=4 validated for this dataset. Real deployments need adaptive K selection or hierarchical clustering.

📅 ANNUAL SCOPE

365-day analysis captures seasonality but assumes stationarity. Multi-year data would reveal behavioral drift.

🎯 FEATURE ENGINEERING

51 features manually curated. Automated feature discovery (deep learning embeddings) could uncover hidden patterns.

NEXT STEPS

Deploy on 3+ real-world meter datasets · Integrate with demand-response APIs · A/B test intervention effectiveness per cluster

# Vendored Anatomy SVG core

iso-kit.mjs is the small SVG geometry and rendering core from [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy), distributed under the adjacent MIT license. It is used by the project-specific method-figure builder in ../anatomy/build_method_instrument.mjs.

The figure itself describes this repository's PCA and K-Means reference analysis. It does not depict literal hardware or claim to execute the analysis in the browser.

## 1. C++ Engine (`cpp_engine/`)

**Status: Implemented. Build and execution are pending the toolchain (`Not yet executed` until built).**

A modular, optional C++17 performance engine behind a pybind11 module (`energy_cpp`).
It re-implements exactly two kernels, PCA and K-Means, and is **not** the
scientific reference. The Python/scikit-learn implementation stays the reference
for every result in the repo.

| File | Purpose |
|------|---------|
| `cpp_engine/include/utilities.hpp` | `Mat` (flat row-major), deterministic `SplitMix64` RNG, steady `Stopwatch` |
| `cpp_engine/include/pca.hpp` / `src/pca.cpp` | PCA via centered covariance plus **symmetric Jacobi eigendecomposition** (classical, stable, no external numeric dependency), sklearn `svd_flip` sign convention, cumulative-variance (0.95) / Kaiser / scree-elbow selection |
| `cpp_engine/include/kmeans.hpp` / `src/kmeans.cpp` | **Lloyd's algorithm** with K-Means++ or random init, `n_init` restarts, `tol` on max centroid shift, empty-cluster relocation to the farthest point, OpenMP-parallel assignment under `#ifdef _OPENMP`, final serial pass for exact labels/inertia |
| `cpp_engine/src/bindings.cpp` | `pca_fit(X, n_rows, n_cols, threshold, max_components)`, `kmeans_fit(X, n_rows, n_cols, k, max_iter, tol, n_init, init, seed)`, `compile_info()` |
| `cpp_engine/CMakeLists.txt` | `energy_engine` static lib plus standalone `energy_bench` plus optional pybind11 module |
| `cpp_engine/setup.py` / `pyproject.toml` | `Pybind11Extension`, `/O2` + `/openmp` (MSVC) or `-O3` + `-fopenmp`; `ENERGY_CPP_NO_OPENMP=1` opt-out |
| `cpp_engine/benchmarks/bench_main.cpp` | Pure-C++ best-of-3 kernel benchmark (no Python) |
| `requirements-cpp.txt` | `pybind11>=2.12,<4` (build-time only) |

Portability: builds with any C++17 compiler; OpenMP is used only when present
and never changes results (deterministic for a given seed). Build artifacts are
git-ignored (`build/`, `*.obj`, `*.o`, `*.pyd`, `*.so`, `*.dll`, `*.lib`).

## 2. Validation

**Status: test-suite Implemented. Bridge tests are pending build to run (they skip cleanly when the module is absent).**

- `tests/test_cpp_bridge.py`. `@requires_cpp` marks every engine test to skip
  with reason `py -m pip install ./cpp_engine` when the module is absent, so
  `py -m pytest` passes either way. When built it checks: sign-aligned PCA match
  vs sklearn (`<1e-6` per component), `cpp_pca_object` sklearn-shaped with the
  three selection rules, `kmeans_fit_numpy` vs sklearn (ARI `>0.99`, inertia rel
  diff `<1e-3`), `CppKMeans` sklearn API, and the `patch_pipeline_kernels`
  round-trip.
- **Fair-comparison contract** (the benchmark never cheats). Identical matrices
  for both engines, `svd_solver='full'` on both sides, same seed / `n_init=10` /
  k-means++ on both sides, best-of-3 after a warmup, K-Means measured on the
  *same* sklearn-PCA scores, labels compared by ARI/AMI (permutation-invariant),
  PCA components compared sign-aligned.
- **Honest-unavailable contract**. With an absent module it writes
  `benchmark_results.json` with `status: "not_executed"` plus a reason and the
  build command. The Streamlit page and the Vercel Performance section render
  that state instead of inventing numbers.

## 9. EXACT COMMANDS

Run every Python entry point from the **project root** with `py` (not `python`).

```bash
# 1. Install dependencies
py -m pip install -r requirements.txt

# 2. Build the C++ engine (optional; the pipeline runs without it)
py -m pip install -r requirements-cpp.txt
py -m pip install ./cpp_engine

# 3. Run the main pipeline (30-day default; flagship year below)
py run_module.py energy_analysis
py run_module.py energy_analysis -- --n_days 365 --n_consumers 200

# 4. Run the C++ integration (bridge exercised end-to-end; skips cleanly if unbuilt)
py -m pytest tests/test_cpp_bridge.py -v

# 5. Run the Python-vs-C++ benchmark (writes outputs/benchmarks/* + web/public/data/benchmark.json)
py src/run_cpp_benchmark.py
py src/run_cpp_benchmark.py --e2e

# 6. Generate artifacts (also auto-run at the end of energy_analysis)
py run_module.py export_artifacts

# 7. Run the full test suite
py -m pytest -q

# 8. Run the Streamlit simulator (16 pages; http://localhost:8501)
py -m streamlit run streamlit_app.py

# 9. Run the Vercel web app (dev) / build (prod)
npm run dev --prefix web
npm run build --prefix web
```
